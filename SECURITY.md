# Security

Only the pinned Minecraft 1.21.1 / NeoForge target is currently maintained.
This is an early addon release; client and full-modpack validation are incomplete.

Report vulnerabilities privately through GitHub's **Security > Report a
vulnerability** page for this repository. Do not put exploit details, tokens,
private server addresses, or player data in public issues.

For ordinary crashes and compatibility bugs, use the bug-report template and
remove personal information from logs before posting.
